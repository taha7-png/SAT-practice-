## ✨ Features

- **♾️ Endless Math questions** — procedurally generated with random values across 15+ templates
- **📖 Bluebook-style English** — real SAT question patterns with shuffled options
- **🗺️ Question Map** — skip, flag, and jump to any question (just like Bluebook)
- **📝 Full 4-Module Exam** — real adaptive timing, scored out of 1600
- **🤖 AI Study Buddy** — a rule-based chatbot for strategy, formulas & grammar
- **🎴 Flashcards** — formulas and key terms, tap to flip
- **📒 Study Notes** — with worked math examples
- **🌗 Dark & Light themes**
- **⚙️ Customizable** — question count, difficulty filter, timer toggles
- **📊 Stats tracking** — day streak, accuracy, correct/attempted (saved locally)
- **📱 Mobile responsive** — works on phones, tablets, and desktops
- **🔌 Zero dependencies** — one HTML file, no build step, works offline
